# Запуск backend

Backend использует PostgreSQL. Перед запуском задайте переменную окружения
`DATABASE_URL` со строкой подключения к подготовленной базе.

Пример для локальной учебной базы, из каталога `backend`:

```powershell
$env:DATABASE_URL = 'postgres://handycraft:YOUR_PASSWORD@localhost:5432/handycraft?sslmode=disable'
go run ./cmd/app
```

Замените имя пользователя, пароль, адрес и имя базы на свои значения.
`sslmode=disable` в примере предназначен для локальной учебной базы;
для удалённой базы используйте параметры TLS, предоставленные её администратором.
Переменная окружения должна быть передана процессу приложения; `.env` автоматически
не читается. Рабочий `docker-compose.yml` пока не передаёт `DATABASE_URL`
и не запускает PostgreSQL.

Сервер проверяет соединение с базой перед запуском HTTP на порту 8080.
Если `DATABASE_URL` отсутствует или база недоступна, приложение завершается
с ошибкой. На попытку подключения отводится 5 секунд. Строка подключения
и ошибка драйвера не выводятся в журнал, чтобы не раскрыть пароль.

Миграции применяются отдельно: см. [инструкцию](migrations/README.md).
Приложение не создаёт и не изменяет таблицы при запуске. Подключение к базе
не заменяет пока существующие заглушки API рабочими обработчиками.
